# GreenToken

**根据任务选择模型与输出预算，再用回答质量、Token、费用估算和耗时评估这次选择。**

GreenToken 是一个在本机运行的 AI 调用与评估工具。你可以直接完成一个任务，也可以对同一任务运行四组策略，查看模型路由和输出控制分别带来了什么变化。

## 可以做什么

- 输入任务和参考上下文，查看基于规则的任务分类、难度判断、模型选择与输出预算。
- 使用自己的 DeepSeek API Key 完成真实调用，或通过不需要 Key 的离线模拟熟悉流程。
- 运行单组任务、两组对照或完整四组实验，查看回答、Token、费用估算和 Latency。
- 保存本机实验，按来源、实验范围、任务关键词和待评价状态筛选记录。
- 对真实回答记录完成情况、1–5 分质量评分及评分说明，导出 JSON 报告或 CSV 指标。
- 查看随项目提供的脱敏案例，了解如何同时判断资源消耗与回答质量。

## 下载与启动（Windows）

需要 **Python 3.11**。首次安装依赖需要联网；安装完成后，离线模拟不需要联网。真实调用另需可用的 DeepSeek API Key 和账户额度。

1. 在本仓库点击 **Code → Download ZIP**，将压缩包完整解压。
2. 打开包含 `README.md`、`showcase.py` 和 `requirements.txt` 的文件夹，在文件资源管理器地址栏输入 `powershell` 并回车。
3. 依次执行以下命令：

```powershell
python --version
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run showcase.py --server.port 8501
```

如果第一条命令无法运行，请先安装 [Python 3.11](https://www.python.org/downloads/release/python-3119/)，安装时勾选 **Add python.exe to PATH**，然后重新打开 PowerShell。

4. 保持命令窗口打开，在浏览器访问 **http://127.0.0.1:8501**。

以后启动可直接双击 `start.cmd`。结束使用时，在运行窗口按 **Ctrl+C**。如果 8501 已被占用，可将启动命令的端口改为 8502，并访问对应地址。

## 第一次使用

### 先熟悉流程：离线模拟

1. 进入 **开始任务**，选择 **离线模拟**。
2. 输入一段任务，例如 `请翻译：绿色技术提高资源利用效率。`。
3. 选择 **对照实验 → 完整四组**，点击 **运行离线示例**。
4. 查看四组回答、资源指标和对比结果。
5. 进入 **实验复盘 → 我的实验**，将数据来源切换为 **离线模拟**，查看刚才保存的记录。

离线模式使用固定回答和模拟用量，只用于体验操作，不会实际完成输入的任务，也不接受真实质量评分。新下载的项目没有个人实验；**示例案例**可直接查看。

### 完成真实任务

1. 选择 **真实 API**，输入任务及可选参考上下文。
2. 在页面输入自己的 API Key，查看请求地址、计划模型、输出预算和请求次数。
3. 初次可选择 **完成任务**，点击 **运行真实任务**：这会执行一次 Full Green 调用。
4. 等待完整回答返回，检查回答是否满足要求，再查看资源指标。
5. 在质量评价中选择策略、完成情况，填写评分与判断说明并保存。也可以稍后从 **实验复盘**继续评价。

Key 在提交后清空，不写入实验数据库。每次点击运行都会重新请求并可能计费；切换页面、筛选、评分和下载报告不会调用模型。失败不会自动重试。

## 四组策略如何比较

| 策略 | 模型路由 | 输出控制 | 用途 |
| --- | --- | --- | --- |
| Baseline · 原始策略 | 使用基准模型 | 使用基准预算 | 作为比较起点 |
| Output Only · 输出控制 | 使用基准模型 | 输出约束指令 + 任务预算 | 观察输出控制的影响 |
| Router Only · 模型路由 | 按任务规则选择模型 | 使用基准预算 | 观察模型选择的影响 |
| Full Green · 组合策略 | 按任务规则选择模型 | 输出约束指令 + 任务预算 | 观察组合效果 |

**完成任务**运行 Full Green 一组；**两组对照**运行 Baseline 和 Full Green；**完整四组**运行全部策略。四组使用相同任务和参考上下文，随机排序后逐组调用，每组一次。对于某些任务，规则选出的模型或预算可能与基准相同。

## 如何理解结果

- **Token**：真实调用使用 API 返回的用量，缺失字段保留为未知，不根据回答长度补造用量。输出 Token 可能包含推理消耗，不等同于可见回答长度。
- **API Cost**：依据用量与项目内的参考价格计算，展示币种、价格版本与估算方式。随包价格快照标记为 2026-11-03，不自动更新，也不等同于账户实际账单。
- **Latency**：一次请求到完整响应返回的耗时，包含网络与服务端等待；不代表首字响应时间。
- **人工评分**：先判断是否完成任务；已完成或部分完成可填 1–5 分，未完成或无法判断不计质量分。建议说明正确性、完整性和是否符合任务要求。

Token 减少不一定意味着费用降低，资源下降也不等于质量保持不变。请结合完成情况和评分解释每次结果；少量案例不能证明普遍收益。GreenToken 不测量碳排放。

## 数据保存与分享

默认勾选 **自动保存到我的实验**，任务原文、参考上下文、回答、资源指标和评价保存在本机 `data/local_experiments.sqlite`。取消勾选后，可在结果页手动保存。重启后已保存的数据仍可查看。

- **JSON**：包含回答、指标和评价；默认不附任务原文与上下文，可自行勾选加入。
- **CSV**：包含返回响应的资源指标和最新评价；调用失败详情请查看 JSON。
- 导出文件中的回答、评分说明也可能包含敏感内容，分享前请检查。
- 发布包不附带个人数据库；`.gitignore` 排除了本机数据库、密钥文件和虚拟环境。请勿将自己的 Key 或个人实验手动上传。

## 配置与常见情况

默认请求 DeepSeek API。模型映射、预算和网络超时配置见 `showcase.config.json`；费用参考见 `showcase.pricing.json`。修改后请重启应用，并确认模型名称与账户权限匹配。本页面通过输入框接收 Key，无需配置 `.env`。

- **等待较久**：页面显示正在运行的组和累计等待时间。目前收到完整响应后才显示回答；四组按顺序执行，耗时可能累加。120 秒网络超时不是整个实验的总时限。
- **没有可见答案 / 达到输出上限**：模型可能将预算用于推理，仍可能产生费用。不要将空答案判为任务完成，也不要把它计为有效节省。
- **401、余额或模型错误**：检查 Key、账户额度及模型权限；项目不会自动重试或用模拟结果替代失败。
- **找不到新记录**：确认保存成功，并检查“真实 API / 离线模拟”等筛选条件。

项目用于可信本机上的个人使用，未提供账号隔离和公网部署配置。

## 项目结构与测试

```text
showcase.py                 页面入口
greentoken/                 任务识别、路由、输出控制、API、计价与实验管理
data/public_cases.json      脱敏案例
showcase.config.json        模型与预算配置
showcase.pricing.json       版本化参考价格
tests/                     页面流程及请求进度测试
```

安装依赖后，可运行离线测试（HTTP 响应使用测试替身，不调用付费 API）：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```
